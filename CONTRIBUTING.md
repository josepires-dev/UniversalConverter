# Contribuição

Contribuições são bem-vindas através de pull requests. Antes de abrir uma alteração, descreva o problema resolvido, mantenha o escopo focado e atualize a documentação quando o comportamento ou a instalação mudarem.

Não inclua binários de terceiros, arquivos temporários, uploads de teste, credenciais ou dados pessoais. Execute a validação de sintaxe PHP disponível no seu ambiente, `php tests/smoke.php` e `php tests/regression.php`. Explique no pull request quaisquer testes que não possam ser executados localmente.

As alterações devem preservar o funcionamento local em Apache/XAMPP, respeitar os limites de upload e manter as proteções contra acesso a redes internas e diretórios temporários.
